[CASE 001 사진 배치 최종 정리본]

이번 버전의 이미지 배치는 다음과 같습니다.

- index.html: 냇물 이미지 제거
- record04.html: 뱀 이미지 제거
- record05.html: 사용자가 제공한 냇물 + 뱀 이미지만 유지
- record06.html: 사용자가 제공한 화재 이미지 유지
- record05.html에 있던 기존 CSS로 만든 냇물/뱀 재구성 이미지 제거
- 기존 CSS의 .water / .snake / .fire 재구성 요소도 제거

교체할 파일:
index.html
record01.html
record02.html
record03.html
record04.html
record05.html
record06.html
record07.html

style.css가 변경되지 않았다면 기존 것을 그대로 사용해도 됩니다.
