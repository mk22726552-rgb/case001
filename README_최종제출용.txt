CASE 001 최종 교수님 제출본

1. QR은 QR_INDEX_하나만.png 하나입니다.
2. QR을 찍으면 INDEX로 들어갑니다.
3. INDEX에서 [사건 기록 시작]을 누릅니다.
4. 각 FILE 하단의 [다음 기록] 버튼으로 FILE 01 → 02 → 03 → 04 → 05 → 06 → 07 순서로 이동합니다.
5. 각 FILE 상단의 INDEX/FILE 메뉴로 원하는 기록으로 바로 이동할 수도 있습니다.
6. QR을 다시 찍을 필요가 없습니다.
7. ZIP을 압축 해제하면 index.html을 더블클릭해서 QR 없이도 전체 사이트를 볼 수 있습니다. (음성은 브라우저/기기에서 지원되는 한국어 음성을 사용합니다.)
8. GitHub Pages에 올릴 때도 기존 HTML/이미지 파일을 그대로 교체하면 됩니다. 기존 QR 주소는 INDEX 주소라서 그대로 사용할 수 있습니다.
