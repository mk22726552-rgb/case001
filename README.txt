# CASE 001 : 천벌 — 인터랙티브 사건기록

## 구성
- index.html : 사건기록 메인 화면
- record01.html ~ record07.html : QR별 사건기록
- style.css : 공통 디자인
- QR_최종교체용_주소목록.txt : 공개 URL을 넣을 자리

## 중요한 점
현재 파일은 웹페이지가 완성되어 있지만, QR이 바로 휴대폰에서 열리려면 이 파일들이 인터넷에서 공개되는 주소가 필요합니다.
파일을 업로드한 뒤 각 페이지의 공개 주소를 QR에 넣으면 됩니다.

## 추천 사용 방식
1. 이 폴더 전체를 정적 웹호스팅에 업로드합니다.
2. 다음 7개 주소를 확인합니다.
   /record01.html
   /record02.html
   /record03.html
   /record04.html
   /record05.html
   /record06.html
   /record07.html
3. 공개 주소를 QR에 연결합니다.
4. 교수님에게는 실제 종이 사건파일을 주고 QR 01부터 순서대로 스캔하게 합니다.

## 발표 연출
- 표지 : CASE FILE 001 / CONFIDENTIAL
- QR 카드를 증거물 카드처럼 배치
- QR 03에서는 실제로 녹음한 심문 음성을 삽입하면 효과적
- QR 05에서는 물소리/뱀소리 같은 효과음을 넣을 수 있음
- QR 06에서는 화재 사진 또는 붉은 조명 사진을 증거물처럼 삽입할 수 있음
- QR 07에서 관객이 사건의 의미를 스스로 판단하게 함

## 주의
이 작품은 원 설화의 사건 순서를 바꾸거나 새로운 사건을 추가하지 않고, '매체'만 사건기록 형식으로 재구성하는 것을 전제로 합니다.
